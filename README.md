**Programme**: B.Tech | **Branch**: CSE-CYS | **Year**: II Year | **Semester**: III | **Section**: B  
**Academic Year**: 2026–2027 | **Regulation**: R25  
**College**: VNR VIGNANA JYOTHI INSTITUTE OF ENGINEERING & TECHNOLOGY

---

## Features
- **74-Student Master Roster**: Strict partitioning into **Batch 1 (37)** and **Batch 2 (37)** with full roll numbers preserved.
- **Dynamic Timetable**: Complete Monday–Saturday schedule with automatic running class detection, continuous multi-hour sessions, and `/` lab batch separation.
- **Strict WhatsApp Formatting**: Formats only the last 2 characters of roll numbers in one continuous line without line breaks, student names, or symbols.
- **Attendance Management**: Save, view, edit, delete, and print attendance sheets.
- **Student History Deep-Dives**: Real-time attendance percentage tracking across all applicable sessions.
- **Reports & Excel Export**: Subject-wise and student-wise attendance tracking with `.xlsx` download.
- **Dark / Light Mode**: Professional ERP theme with system preference detection and persistence.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Application (Backend + Frontend)
```bash
npm run dev
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`

### 3. Production Build
```bash
npm run build
```
